~~~powershell

python 09-practice/check.py show VA01
python 09-practice/check.py grade VA01

# 2. 读流程主线，建立全局地图
#    01-workflow/README.md
~~~

故障题的初始判题失败是**题目设计**，不是安装出了问题。

## 这个仓库不假设什么

- 不假设你有 GPU。多数章节在没有设备时仍然可读、可练，只是无法得到真实硬件数字。
- 不假设你有 CUDA 经验。基础概念在 [02-foundations](../02-foundations/README.md) 从零讲。
- 不假设你读过任何一篇论文。进阶章节会给出处，但正文自足。

## 这个仓库假设什么

- 你会写循环、条件、函数，能读懂指针和数组。
- 你知道矩阵乘是什么。
- 你愿意**先写预测再测量**，而不是先看结论再找证据。这是全套材料反复要求的工作方式。
